**0:25–1:00 — The basket.** Keep the 20 kg beans, 30 kg carrots and 20 kg tomatoes example. It produces LKR 14,750. Explain why the current release uses the latest-price baseline. Change carrots to 40 kg; show the additive estimate, joint range, cost shares and budget headroom. Lower the spending limit to 15,000 to demonstrate a budget warning. An upper bound is a planning reserve, not a guaranteed maximum.

**1:00–1:25 — A traceable plan.** Save the basket and export the CSV. Show the issue date, target window, model version and source hash. Open Saved baskets. Explain that browser-hosted IndexedDB saves stay on this device, safely across tabs; the local FastAPI version uses SQLite. Show Export/Restore backup.

**1:25–1:50 — An outcome you can inspect.** Select 16 June 2025 in the planner, save a second basket and inspect its observed benchmark comparison. It is a retrospective replay; we are not claiming a prospective issuance. Return to March 2026 to show that an unavailable next-week label stays unavailable.
